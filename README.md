# Ronald Mat - Personal Portfolio

A modern, minimalist portfolio website built with Next.js, showcasing my journey as a junior software developer with a focus on cybersecurity and networking.

## 🛡️ About

This portfolio website serves as a central hub for my projects, articles, and professional information. It features a clean, responsive design with dark mode support and focuses on presenting my work in cybersecurity, networking, and software development.

## ✨ Features

- **Responsive Design**: Optimized for all device sizes
- **Dark/Light Mode**: Automatic theme detection with manual toggle option
- **Projects Showcase**: Highlighting featured and all projects
- **Articles Section**: Sharing my learning journey and insights
- **Modern UI**: Clean, minimalist interface with smooth transitions
- **SEO Optimized**: Including proper metadata and favicon

## 🚀 Tech Stack

- **Framework**: Next.js
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Deployment**: Vercel

## 🔧 Getting Started

### Prerequisites

- Node.js (v14 or later)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone git@github.com:glitchbytez/ronald-mat.git

# Navigate to the project directory
cd my-dev-main

# Install dependencies
npm install
# or
yarn install
```

### Development

```bash
# Start the development server
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

### Build

```bash
# Build for production
npm run build
# or
yarn build

# Start the production server
npm start
# or
yarn start
```
